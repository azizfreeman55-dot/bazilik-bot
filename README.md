# 🍱 Lunch Bot — Система заказа обедов через Telegram

## Структура проекта
```
lunch_bot/
├── main.py                  # Точка входа
├── config.py                # Настройки и конфиги
├── requirements.txt         # Зависимости
├── .env                     # Токены (не публиковать!)
├── database/
│   └── db.py               # Все запросы к БД
├── handlers/
│   ├── __init__.py         # Регистрация роутеров
│   ├── registration.py     # /start, регистрация
│   ├── orders.py           # Заказы
│   ├── profile.py          # Профиль, лояльность, рейтинг
│   └── admin.py            # Панель администратора
├── keyboards/
│   └── keyboards.py        # Все клавиатуры
└── scheduler/
    └── jobs.py             # Уведомления по расписанию
```

## Быстрый старт

### 1. Установите зависимости
```bash
pip install -r requirements.txt
```

### 2. Создайте .env файл
```bash
cp .env.example .env
```
Отредактируйте .env:
- `BOT_TOKEN` — токен от @BotFather
- `ADMIN_IDS` — ваш Telegram ID (узнать у @userinfobot)

### 3. Запустите бота
```bash
python main.py
```

## Функции

### День 1 (готово ✅)
- Регистрация пользователей с реферальными кодами
- Меню на завтра
- Приём и отмена заказов до 20:00
- Фиксация заказов в 20:00
- Уведомления: 10:00 / 16:00 / 20:00
- Система лояльности (баллы, статусы)
- Рейтинг компаний
- Панель администратора

### День 2 (следующий шаг)
- Автозаказ
- Меню на неделю
- Детальная аналитика
- Маршруты доставки

## Деплой на Railway

1. Зарегистрируйтесь на railway.app
2. Создайте новый проект → Deploy from GitHub
3. Добавьте переменные окружения в Settings → Variables
4. Готово! Бот работает 24/7
